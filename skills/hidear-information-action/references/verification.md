# 信息核验清单

1. 原始出处：机构、公告名称、完整 URL、是否为官方原文；转载与搜索摘要不能替代原文。
2. 时间：发布日期、生效日、报名截止日、采集/核验时间，默认按公告所在地时区解释；不明日期保留未知。
3. 适用范围：地域、对象、年龄等公告明确条件，不能补写未公布门槛。
4. 行动要求：材料、官方报名入口、办理方式、费用、公开联系方式。
5. 状态：未核实、部分核实、已核实、过期、撤回；说明证据和缺口。
6. 来源变化：更新公告或撤回优先于旧版本；冲突时指出冲突并建议联系主办方。
7. 用户匹配：条件满足/信息缺失/公开条件不匹配，仅作辅助说明。

核验报告示例字段：source_url、publisher、published_at、deadline_at、checked_at、verification_status、verified_fields、unknown_fields、source_version。字段缺失使用 null/空列表，不猜测。
